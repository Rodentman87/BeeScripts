# beefiles.txt -- the list beeupdate installs from.
#
# One entry per line:   <source in repo>   <install path>   [keep]
#   "keep" = fetch only when the file is missing, so your local
#            edits are never clobbered.
# Blank lines and lines starting with # are ignored.
#
# Add a new module here and `beeupdate` picks it up on the next run
# -- the updater itself never needs re-deploying for that.
#
# beebot.lua is deliberately absent: it lives on the ROBOT's
# filesystem, not the PC's, and is installed by hand.
